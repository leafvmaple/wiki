## 状态约定

| 状态 | 用途 |
| --- | --- |
| 草稿 | 页面结构已建，但内容未完整验证 |
| 待验证 | 有线索或经验判断，但缺少实测、截图或来源 |
| 已验证 | 关键数值、路线或机制已按当前版本确认 |
| 已过期 | 页面仍有参考价值，但已不适配当前版本 |
