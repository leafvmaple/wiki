## 数据来源

当前资料由本机 `D:\Code\tdj-godot` 生成，主要使用这些文件：

- `data/db/characters.json`
- `data/db/level_up.json`
- `data/db/skills.json`
- `data/db/monsters.json`
- `data/battles/*.json`
- `data/camp/camps.json`
- `data/db/items.tres`

## 同步方式

在 wiki 仓库执行：

```powershell
npm run generate:tdj
```

如果 `tdj-godot` 不在默认路径，可以指定来源目录：

```powershell
node scripts/generate-tdj-data.mjs "D:\Code\tdj-godot"
```

角色表中的成长字段来自升级表；关卡表目前只做结构化统计，不把未确认的剧情章节名写入页面。后续如果在 `tdj-godot` 中补齐关卡名、胜败条件、宝箱或掉落字段，重新生成后可以继续扩展本分区。
