四件常被讨论的战斗道具的实际机制，结论来自 FC 日版 ROM 反汇编，并与汉化版逐字节对比。判定摘要见[传闻判定一览](/games/metal-max/research/)。

| 道具 | 日版实际效果 | 汉化版差异 |
| --- | --- | --- |
| 浓缩甲醇 | 基础攻击力 500，单体无属性，**无限使用** | 相同 |
| 战车烟幕弹 | 敌组全体命中/回避系数减半，可叠加，持续整场 | 相同 |
| 人类烟幕花火 | 仅使用者 78.125% 闪避，持续整场 | 相同 |
| 军号 | 全队速度 +16 可叠加，1/8 概率损坏 | **单字节 BUG，变成神器** |

## 浓缩甲醇（のうしゅくメチル）

- 使用脚本没有「删除道具」指令，因此**不是消耗品**，战斗中可反复使用（对比手雷、火瓶等投掷品的脚本以删除指令开头）。
- 基础攻击力 **500**（威力表 PRG `0x22D91`/`0x22D9C` 索引 9 = `0x01F4`），单体、无属性，不读取敌人的火焰/寒冷/气体抗性。
- 走普通伤害公式：会继续计算战斗等级差、目标防御的一半和随机浮动，对战车类目标伤害再除以 5——所以是「基础攻击 500」，不是「固定扣 500 HP」。
- 与完整激光炮（四镜片 `レーザーバズーカ`）同走无属性普通伤害，且激光炮的攻击索引同样解析到 500：两者的差距只在武器攻击会再加上人物力量。**「仅次于完整激光炮」成立，「没有作用」与 ROM 不符。**

## 战车烟幕弹（えんまくだん）

- 特殊炮弹 `S08`，走战车特殊炮弹的独立分派，一发只扣一发弹药，但**作用于所选敌组的每个存活敌人**。
- 核心指令对每个敌人执行两次「减半」（CPU `$B861`：`LSR $72DE,X` / `LSR $72E7,X`），把敌人的**命中**和**回避**两个战斗系数同时砍半；重复使用继续减半（`v → v/2 → v/4 → … → 0`），没有回合倒计时，持续到战斗结束。
- 这两个系数直接进双方共用的伤害修正公式：按攻守系数差查表，修正幅度 0–50%（表值 `00 0D 1A 27 33 41 4E 5A 66 73 80`，即 0%、5%、…、50%）。敌人回避系数减半 → 我方伤害修正向正方向移动；敌人命中系数减半 → 敌方伤害修正向负方向移动。
- 所以「用了烟幕弹之后攻击力也变高」的体感是真的：面板攻击不变，但在极端系数差下，同一基础攻击的修正可以从 `0.5A` 摆到 `1.5A`，扣防御后的显示伤害差距还会更夸张。
- 日版与汉化版在分派表、脚本、处理器和伤害公式上逐字节一致——**这是日版原生机制，不是汉化版 BUG**。

## 人类烟幕花火（えんまくはなび）

与战车烟幕弹**完全不同的两条程序路径**，不要混为一谈：

- 消耗品；使用后把**使用者本人**的闪避档写到最高档 4（处理器 `$A94C`），普通伤害入口的闪避概率是 `0xC8/256` = **78.125%**，持续整场；再用一次仍是档 4，不叠加，也不保护另外两名队友。
- 这是「78% 概率完全不吃普通伤害」，不是「伤害降低 78%」；绕过普通伤害入口的专用异常攻击不受它拦截。
- 对整个 PRG 做绝对地址交叉引用：闪避档 `$7079/$708E` 只有初始化、烟幕花火写入、上下车参数交换和受击判定四类访问点，**不进入任何攻击力或伤害计算路径**。「用了之后伤害变高」来自伤害的随机浮动与行动顺序（随机数消费序列）变化。

## 军号（しんぐんラッパ）

### 日版：平凡的加速道具

- 使用后**全队三人**战斗速度各 +16，可反复叠加，单字节饱和到 255；只影响先手，不加攻击力；效果只保留到本场战斗结束。
- 每次使用后判断损坏：随机字节低 4 位为 0 或 1 时军号消失，即每次 **1/8（12.5%）** 概率损坏；先加速后判损坏，损坏的最后一次仍然生效。按几何分布平均可吹 8 次。

### 汉化版：单字节错误造出的神器

汉化版把军号效果例程（file `0x20010`）的第一条指令改坏了一个字节：

```text
日版:   A2 02 …   LDX #$02      ; 循环 3 次，只写 3 人速度
汉化版: 01 02 …   ORA ($02,X)   ; X 不再被赋值
```

进入例程时 X 残留着调用链留下的 `0x10`，于是「+16」循环从 3 字节越界扩大到 **17 字节**（`$706A–$707A`），每吹一次：

| 被污染字节 | 正常用途 | 实际影响 |
| --- | --- | --- |
| `$706A–$706C` | 三人战斗速度 | 正常的全队 +16 |
| `$706D–$7072` | 三人当前防御（16 位 ×3） | 低、高字节各 +0x10，**防御每次暴增约 4112** |
| `$7073–$7075` | 攻击侧战斗等级 | 每人 +16，命中与伤害浮动被抬高 |
| `$7076–$7078` | 防守侧战斗等级 | 每人 +16，进一步压低敌方伤害 |
| `$7079–$707A` | 主角与机械师的闪避档 | 越界到非法档位，按落点字节决定闪避率（第一次吹后约 81.6%） |

防御暴增 4112 足以让大量普通攻击直接打出最低伤害，是汉化版军号最稳定的收益；闪避档污染则不单调（再吹落点会变，与烟幕花火联用甚至会把合法的 78.125% 改坏成 43.75%）。女战士的闪避档恰好在 17 字节之外，但她的速度、防御和战斗等级同样被改。

**结论：军号 = BUG 神器只对汉化版成立，根源是一个字节的指令污染；日版军号只是普通的加速消耗品。**
