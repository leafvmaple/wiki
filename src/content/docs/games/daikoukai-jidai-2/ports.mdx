共 **100 个普通港口**。可按地区、开局归属、特产和设施筛选，也可搜索港名、交易品或
[自由航海士](../officers/)；点击表头可排序。

:::tip[阿里的铁矿石敕命]
这次敕命需要 **10 份铁矿石**。离伊斯坦布尔较近的是 **カッファ（卡法，N45 E034）**：铁矿石是当地
特产，商业值达到 **400** 后出售，开局商业为 340，当前值不足时先投资交易所。无需投资的确定产地是
**ロンドン（伦敦）**和 **アムステルダム（阿姆斯特丹）**，两港开局商业已经达到北欧铁矿石所需的 700。
チュニス（突尼斯）也有铁矿石特产，但要把商业提高到 600，通常不如卡法方便。
:::

:::note
归属、商业和工业均为开局值，游戏中会随投资和月份推进而变化。
:::

## 交易品规则

每个普通港口出售所属交易地区的共同商品；部分港口另有一种特产。商品只有在港口当前商业值达到表中
要求后才会出现，商业值会随玩家和各国商船队投资而变化。

- **基准价**：物价 100% 时购买 10 份商品的参考价格；实际报价还受行情、交易税和交涉影响。
- **商业**：商品出现所需的港口商业值。港口表的商业列是开局值。
- 港口表搜索会同时匹配特产和地区共同商品。例如搜索“铁矿石”会列出卡法、突尼斯，以及北欧、南美的港口。

## 设施说明

所有普通港口都有港口、宿屋、酒馆、交易所、造船所和公会，表格只列出其他设施。

| 设施 | 用途 |
| --- | --- |
| 银行 | 存取款、借款及购买保险 |
| 教会 / 清真寺 | 捐献并提高相应地区的声望 |
| 道具店 | 购买普通道具；`02:00–02:30` 出售隐藏商品 |
| 占卜屋 | 查询航海士状态和运势 |
| 酒馆女郎 | 交谈、赠送发现物和打听消息 |
| 收藏家 | 报告发现物并领取报酬 |
| 地图工房 | 购买地图制作服务 |
| 测量 / 炮术 | 学习对应技能 |

## 营业时间

| 设施 | 营业时间 |
| --- | --- |
| 港口、宿屋 | 全天 |
| 交易所、造船所、公会、银行 | `04:00–19:30` |
| 道具店 | `08:00–19:30`；隐藏商品 `02:00–02:30` |
| 教会、清真寺 | `04:00–23:30` |
| 占卜屋 | `16:00–23:30` |
| 酒馆 | `08:00–次日 03:30` |

:::tip[补给港]
世界上另有 [30 个补给港](../supply-ports/)，可补充水、粮食、修理材料和炮弹，不计入本表。
:::
