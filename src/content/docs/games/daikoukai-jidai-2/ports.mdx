## 设施说明

所有普通港口都有港口、宿屋、酒馆、交易所、造船所和公会，表格只列出其他设施。

| 设施 | 用途 |
| --- | --- |
| 银行 | 存取款、借款及购买保险 |
| 教会 / 清真寺 | 捐献并提高相应地区的声望 |
| 道具店 | 购买普通道具；`02:00–02:30` 出售隐藏商品 |
| 占卜屋 | 查询航海士状态和运势 |
| 酒馆女郎 | 交谈、赠送发现物和打听消息 |
| 收藏家 | 报告发现物并领取报酬 |
| 地图工房 | 购买地图制作服务 |
| 测量 / 炮术 | 学习对应技能 |

## 营业时间

| 设施 | 营业时间 |
| --- | --- |
| 港口、宿屋 | 全天 |
| 交易所、造船所、公会、银行 | `04:00–19:30` |
| 道具店 | `08:00–19:30`；隐藏商品 `02:00–02:30` |
| 教会、清真寺 | `04:00–23:30` |
| 占卜屋 | `16:00–23:30` |
| 酒馆 | `08:00–次日 03:30` |

:::tip[补给港]
世界上另有 30 个补给港，只提供水、粮食、木材和炮弹补给，不计入本表。
:::
