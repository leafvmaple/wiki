本页收录《大航海时代 II》的 **100 个普通港口**。表格优先回答实际航行时最常见的问题：港口在哪里、
开局属于谁、发展基础怎样、属于哪个交易与造船圈、有哪些稀有设施，以及开局能找到哪些自由航海士。

:::note[适用版本与验证边界]
港名采用 Steam 版可直接对照的日文名称；普通自由航海士与初始港口的关联来自 Steam 用户盘人物记录。
港口顺序、坐标、开局发展值、归属和设施目前以《大航海时代 II》基础版公开资料交叉整理，尚未在 Steam
版 PC-98 数据中完成逐字段定位，因此本页整体暂标为待实机复核。
:::

## 表格应该显示什么

| 信息 | 为什么放在主表 | 解释 |
| --- | --- | --- |
| No. 与日文港名 | 便于对照游戏画面、人物记录和其他资料表 | No. 是本页采用的稳定列表顺序，不是存档偏移 |
| 收益地区与坐标 | 用于规划航线和按大区筛选 | 坐标沿用游戏常见的 `N/S + E/W` 表示 |
| 开局归属 | 反映剧本开始时的势力分布 | 除首都外，投资和时间推进可能改变归属 |
| 开局商业 / 工业 | 快速判断初始发展基础 | 这是开局值，不是当前存档值 |
| 交易圈 / 造船圈 | 决定后续商品与船型资料如何分组 | 主表只显示分区，完整商品和船只另做专题 |
| 特色设施与邸宅 | 找银行、宗教设施、道具店、占卜屋和特殊服务时最有用 | 共通设施不在每行重复 |
| 初始自由航海士 | 把港口规划与[航海士雇佣](../officers/)直接连起来 | 只表示开局配置，不代表游戏中永远停留于此 |

不把“当前物价指数、当前商业值、当前工业值、当前支持国家”写成静态列，是因为这些值会随投资、交易和
月度更新变化。将它们混进攻略表，会让开局资料看起来像任意时刻都成立。

## 设施列怎样阅读

普通港口共通的港口、宿屋、酒馆、交易所、造船所和公会不在每一行重复。表格只列出有区分价值的设施：

| 标记 | 用途 |
| --- | --- |
| 银行 | 存取款、借款及购买保险 |
| 教会 / 清真寺 | 捐献并提高相应地区的声望 |
| 道具店 | 购买普通道具；特定时段还可能出现隐藏商品 |
| 占卜屋 | 查询航海士状态、运势等提示 |
| 酒馆女郎 | 表示该港酒馆有可互动的女郎角色 |
| 邸宅·收藏家 | 把发现物交给收藏家并领取报酬 |
| 邸宅·地图工房 | 购买地图制作相关服务 |
| 邸宅·测量 / 炮术 | 学习对应技能 |

公开的 SFC/Switch 资料给出的常用营业时间为：港口与宿屋全天开放；交易所、造船所、公会和银行通常在
`04:00–19:30`；道具店通常在 `08:00–19:30`，隐藏商品时段为 `02:00–02:30`；教会与清真寺通常在
`04:00–23:30`；占卜屋在 `16:00–23:30`；酒馆在 `08:00–次日 03:30`。Steam 版仍以实际进店结果为准。

## 为什么不把商品和船只全部塞进来

交易品并不是简单的“港口固定一列”：游戏按 **13 个交易圈**组织商品，同一圈内还有港口特产和随商业值
解锁的商品。船只也要结合造船圈、工业值与改造能力阅读。若把商品、价格门槛和船型全展开，100 行主表会
变成难以搜索的超宽表。因此本页只保留交易圈、造船圈和发展值，后续分别建立交易品与船只专题。

## 补给港为什么另算

世界上另有 **30 个补给港**，主要用于补充水、粮食、木材和炮弹。它们没有普通港口的商业、工业、归属、
设施和自由航海士结构，因此不应和这 100 个普通港口混在一张表中；后续会单独整理坐标与航线用途。
