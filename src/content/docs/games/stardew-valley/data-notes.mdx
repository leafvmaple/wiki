《星露谷物语》专区会使用本地整理资料校验数值、规则、地图和事件条件，并把公开页面需要的部分整理成派生数据。

## 可以公开的内容

| 类型 | 说明 |
| --- | --- |
| 自己整理的攻略 | 路线、建议、解释、注意事项 |
| 派生统计 | 数量、筛选结果、利润计算、条件摘要 |
| 少量自制截图 | 用于说明具体玩法或地图位置 |
| 手工整理的点位 | 传送点、商店、任务点、NPC 路线摘要 |

## 不直接公开的内容

| 类型 | 说明 |
| --- | --- |
| 本地资源包 | 不把完整资源文件作为站点资源发布 |
| 完整对白库 | 不发布可替代游戏体验的大段原文文本 |
| 完整贴图表 | 不把角色、物品、地图贴图批量做成公开素材库 |
| 可还原游戏内容的数据包 | 不提供可直接替代游戏本体的数据镜像 |

## 本地到公开的流程

1. 本地读取整理资料。
2. 生成最小化的派生 JSON。
3. 只保留攻略站需要的字段。
4. 页面从派生 JSON 生成表格、筛选和工具。
5. 每次更新后运行 `npm run build`。

## 计划生成的数据

| 数据 | 公开用途 |
| --- | --- |
| 作物摘要 | 季节、生长天数、再生、收获物、利润 |
| 鱼类摘要 | 时间、季节、天气、地点、难度 |
| 村民摘要 | 生日、可攻略、礼物偏好、日程入口 |
| 地图点位 | 传送、门、商店、NPC 路线和交互点 |
| 机器规则 | 输入、输出、概率、收益提示 |
