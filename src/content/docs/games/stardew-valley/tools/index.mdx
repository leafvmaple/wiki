这个板块用于放传统条目页不够顺手的查询器和计算器。工具默认在浏览器端运行，不需要账号、后端或上传数据。

<StardewToolsPanel />

## 工具状态

| 工具 | 回答的问题 | 状态 |
| --- | --- | --- |
| 今日可钓鱼 | 当前季节、天气、时间能钓什么 | 已可用 |
| 作物播种估算 | 这个季节种什么、最后哪天能种 | 已可用 |
| 礼物快查 | 某 NPC 喜欢什么、今天是否生日 | 已可用 |
| [存档辅助](/games/stardew-valley/tools/save-helper/) | 本地读取存档并显示基础进度 | 试点可用 |
| 收集包规划 | 还缺什么、还差几项 | 已可用 |
| 机器加工 | 物品放进机器产什么、收益多少 | 已可用 |

## 存档工具边界

后续可以做存档进度分析，但必须只在浏览器本地读取文件，不上传、不保存、不接账号。
