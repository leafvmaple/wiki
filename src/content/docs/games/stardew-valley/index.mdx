## 建设顺序

| 阶段 | 内容 |
| --- | --- |
| 1 | 建立专区骨架、导航入口、截图和数据目录约定 |
| 2 | 从本地整理资料生成公开可用的派生数据 |
| 3 | 生成作物、鱼类、村民、机器、商店索引 |
| 4 | 做第一个可交互地图试点 |
| 5 | 做作物、钓鱼、礼物、收集包和加工工具 |

:::note[内容边界]
本专区会使用本地资料做校验和派生统计，但公开页面不发布可替代游戏本体的资源包、完整文本库或批量素材库。
:::
