这个板块用于承载《星露谷物语》的大地图和区域点位。第一轮不直接发布原始 TMX 或完整地图素材，而是从本地数据中提取适合攻略使用的派生信息。

## 第一批地图

| 地图 | 目标内容 | 状态 |
| --- | --- | --- |
| 鹈鹕镇 | 门、商店、NPC 常驻点、任务点、区域出口 | 待做 |
| 农场 | 建筑、可耕作区域、传送点、常用设施 | 待做 |
| 沙滩 | 鱼店、潮汐池、传送点、季节活动入口 | 待做 |
| 深山 | 矿井、木匠店、温泉、湖泊钓鱼点 | 待做 |

## 点位类型

| 类型 | 资料基础 |
| --- | --- |
| 传送和出口 | TMX `Warp` 属性 |
| 门和特殊交互 | TMX `Action` / `TouchAction` 属性 |
| 障碍和不可通行区 | TMX 图层与 `NPCBarrier` 等属性 |
| 商店入口 | `Data/Shops.json` 与地图交互点 |
| NPC 路线 | `Characters/schedules/*.json` 与地图 warp |

## 试点目标

先做一个静态可查版本：地图页展示底图、点位表和筛选。等数据稳定后，再升级成可缩放、可点击、可筛选的交互地图组件。
