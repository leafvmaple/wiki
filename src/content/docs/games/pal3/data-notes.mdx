## 同步方式

在 `pal3-unpack`：

```powershell
python tools\gen_wiki_data.py --install-wiki
```

写入 `D:\Code\wiki\src\data\pal3\generated\`。

map-viewer（Metal Max 契约，对齐 NAS `\\10.0.0.20\docker\map-viewer\data\res\metal_max`）：

```powershell
python tools\export_to_map_viewer.py
python tools\export_to_map_viewer.py --nas
```

## 字段口径

- **分类 / 武器类 / 可装备 / 效果 `$` 摘要 / 价格**：同前一版说明。
- **仙术类型**：`Skill_Type` → 辅助/攻击/治疗/合灵；特技为 type 0。
- **商店**：`DealScript` 的 `Equip`/`Prop` 货架 ID 关联 attrib；客栈读 `M_RestPrice`。
- **大地图地点**：SCE 脚本名 → 场景包代码（如安宁村→`Q07`）；`mapX`/`mapY` 为 Element 模板匹配中心（原生 1536×1024），`matchScore` 为匹配分。
