## 结局条件

| 结局 | 条件 | 路线作用 |
| --- | --- | --- |
| BE | 当前 HP 归零，或检查不合格且无法延期 | 单独存档回收 |
| NE | 最终检查合格，幸福度低于 300 | Save 01 分支 |
| HE | 幸福度至少 300，MaxHP 在 300 到 399 | Save 02 分支 |
| TE | 幸福度至少 300，MaxHP 至少 400 | 主干终点 |

## 执行顺序

1. 从新游戏开始，按主干路线推进到 Save 01。
2. Load Save 01，执行 NE 分支表，最终检查合格后进入 NE。
3. 回到 Save 02，停止继续收集并推进最终检查，进入 HE。
4. 回到 Save 03，按低 HP 分支回收 BE。
5. 回到 Save 02 或继续主干，推进到第 86 步，最终检查合格后进入 TE。
