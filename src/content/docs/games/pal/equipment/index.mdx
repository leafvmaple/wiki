部位与属性加成取自 `OBJECT_ITEM` 的装备脚本（opcode `0x0018` 定部位、`0x0017` 定属性），
图标取自 `BALL.MKF`，说明取自随游戏分发的社区整理档 `desc_chs.dat`。

对象类型按 ID 区间判定而非 flags —— 法术与装备的可用位重叠，早先按 flags 筛会混入约一百条法术。
