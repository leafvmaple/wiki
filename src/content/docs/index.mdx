## 内容原则

| 原则 | 写作要求 |
| --- | --- |
| 先解决问题 | 标题直给，开头说明适用版本、阶段、角色或地图 |
| 可维护 | 频繁变化的信息标注适用版本、最后验证日期和内容状态 |
| 可检索 | 数值、材料、掉落、路线优先用表格或清单 |
| 可怀疑 | 不确定的结论标为「待验证」，不要写成定论 |
