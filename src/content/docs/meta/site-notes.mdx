## 技术栈

本站使用 Astro Starlight 搭建，内容来源位于 `src/content/docs/`，使用 Markdown/MDX 编写。

## 视觉方向

站点继承 leafvmaple / moments 的视觉 token：

| token | 值 |
| --- | --- |
| 主色 | `#23b7e5` |
| hover | `#1ba0c9` |
| 字体 | `Source Sans 3` + 中文系统字体 |
| 圆角 | `6px` |
| 暗色背景 | `#1a1a1a` |

不复制 moments 的博客结构、音乐播放器、旅行卡片或个人侧栏。这里保留 Starlight 的侧边栏、目录、搜索、表格和 callout。

## 部署

站点配置域名为 `https://wiki.leafvmaple.com`。`public/CNAME` 用于 GitHub Pages 自定义域名，`public/robots.txt` 指向自动生成的 sitemap。

## 内容边界

这里写游戏攻略和资料库，不混入游记、生活博客、相册或 code 站技术文章。
